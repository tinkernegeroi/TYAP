# Грамматика варианта 10

Начальный символ — `I`. Буквенные обозначения взяты из «Грамматика.docx». Нетерминал `P` обозначает непустой список команд в основном блоке. `D` обозначает непустой список присваиваний в теле `REPEAT`.

```text
I → A B
A → BEGIN P END
B → VAR C : LOGICAL
C → L | L , C
P → E | E P | O | O P
D → E | E D
E → L = F ;
F → H G | G
G → ( F ) | K | G J G
H → NOT
J → AND | OR | IMP
K → L | M
L → N L | N
M → 0 | 1
O → READ ( C ) ; | REPEAT D UNTIL F ; | WRITE ( C ) ;
```

`N` обозначает латинскую букву в исходном документе. На уровне лексем парсер использует `L → ID`: лексер уже распознал имя целиком. Лексемы констант становятся терминалами `0` или `1` по своему тексту.

Грамматика сохраняет правило `G → G J G`. При выборе между переносом и свёрткой автомат сравнивает бинарные операции. Порядок от более сильной к более слабой — `AND`, `OR`, `IMP`. При равенстве выполняется свёртка, поэтому `A IMP B IMP C` группируется как `(A IMP B) IMP C`.

Правило `F → H G` задаёт область действия `NOT`. Например, `NOT A OR B` разбирается как `NOT (A OR B)`. Для отрицания только первого операнда используйте `(NOT A) OR B`.
